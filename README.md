# 🧠 Mental Health Tracker

A full-stack Mental Health Tracker built with the MERN stack (MongoDB, Express.js, React.js, Node.js) that allows users to:

- Log and track their moods daily
- View mood trends and charts
- Receive AI-powered summaries and insights
- Chat with an AI assistant for mental support
- Customize theme and view modes (light/dark)
- Contact professionals through consultation or message

---

## 🚀 Features

- User Authentication with JWT
- Mood Entry with intensity, triggers, activities, symptoms
- Data Visualization with Charts
- AI Mood Analysis (OpenRouter/OpenAI)
- AI Chat Support
- Theme Customizer & Dark Mode
- Contact Us form (with Nodemailer support)

---

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Axios, React Router
- **Backend:** Node.js, Express.js, MongoDB Atlas, Mongoose
- **AI Services:** OpenRouter API
- **Mailing:** Nodemailer (Gmail SMTP)
